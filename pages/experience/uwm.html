01 / Data engineering

Reduce duplicate data before migration.

I normalized databases using third normal form (3NF), reducing duplicates by 45%. The schema work helped accelerate the migration to Google Cloud Platform (GCP) by three weeks.

The focus was on the structure of the data being migrated. Normalization reduced redundancy in the source databases and shortened the migration timeline.

02 / Machine learning

Classify loan outcomes with a random forest.

I implemented a random forest model to classify loan outcomes, identifying whether a proposal should be accepted or rejected. The classification project saved $20,000.

03 / Impact

Measure data quality, time, and cost.

The normalization project reduced duplicate data by 45% and accelerated the GCP migration timeline by three weeks. The loan-classification project delivered $20K in savings.

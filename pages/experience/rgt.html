01 / Customer automation

Ground support responses in company data.

I developed a retrieval-augmented generation (RAG) customer support system using company data. The system resolved 80% of inquiries with 90% accuracy.

The workflow retrieves relevant company context for response generation, connecting the support answer to the knowledge available within the company.

02 / Application performance

Reuse responses to reduce API traffic.

I added Redis-backed caching to a React application, reducing redundant API calls and saving $1,200 per month in API request costs.

A cached response can satisfy a repeated request without another API call. The diagram shows the cache-hit and cache-miss paths at the application level.

03 / Impact

Track support quality and recurring cost.

The support system resolved 80% of inquiries with 90% accuracy. The caching project reduced repeated API requests, saving $1.2K each month.
